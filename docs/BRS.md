# Business Requirements Specification – QSysProfile

| ID | Requirement |
|----|-------------|
| BR-1 | Predict the two-qubit gate count of a circuit family before transpilation. |
| BR-2 | State how accurate closed-form and small-size polynomial fits are when extrapolated to larger circuits. |
| BR-3 | Quantify the extra two-qubit gates caused by limited connectivity (line, grid). |
| BR-4 | State that no device was used and that results depend on the transpiler version. |

Out of scope: execution on hardware, noise, fidelity prediction, T-count / fault-tolerant estimates.
